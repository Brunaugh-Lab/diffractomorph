# Data and calibration licensing

The MIT License covers source code and software documentation. It does not grant
rights to independently sourced scientific data.

The synthetic minimal example is generated solely for software testing and may be
used, modified, and redistributed under the repository's MIT License.

The private development repository also contains CFZ calibration artifacts, derived
optical/noise profiles, and PAQXOS/NIST-standard exports. These files are excluded from
the default public snapshot. They must not be published until provenance and
redistribution rights are approved and a separate data license is selected. The
manuscript reproduction bundle will reference a versioned data archive with checksums.
